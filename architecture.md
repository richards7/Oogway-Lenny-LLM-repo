# Architecture Specification: The Lenny Growth Assistant

## 1. System Overview & Component Diagram

```
[ Frontend (React + Vite) ]
          │
          │ REST API (JSON)
          ▼
[ FastAPI Application ]
  ├── CORS & Logging Middleware
  ├── Routers (/health, /sessions, /artifacts, /config)
  ├── Classifier (Intent Tool Classifier)
  ├── Agent Orchestrator
  │     ├── Tool 1: retrieve_and_answer
  │     ├── Tool 2: write_ship30_essay
  │     └── Tool 3: generate_artifact
  ├── Sanitizer (HTML Security Stripper)
  └── LLM Provider Abstraction
        ├── OllamaProvider (Local http://localhost:11434)
        ├── AnthropicProvider (Claude API)
        └── OpenAIProvider (GPT-4o API)
          │
          ├── Embeddings: sentence-transformers/all-MiniLM-L6-v2 (384D, CPU-forced)
          ▼
[ PostgreSQL + pgvector ]
  ├── sessions
  ├── messages
  ├── sources
  ├── chunks (ivfflat cosine index)
  └── artifacts
```

## 2. Database Schema (PostgreSQL + pgvector)

```sql
CREATE EXTENSION IF NOT EXISTS vector;
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

CREATE TABLE sessions (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    client_metadata JSONB DEFAULT '{}'::jsonb
);

CREATE TABLE messages (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    session_id UUID NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
    role VARCHAR(20) NOT NULL CHECK (role IN ('user', 'assistant', 'tool')),
    content TEXT NOT NULL,
    citations JSONB DEFAULT '[]'::jsonb,
    model_provider VARCHAR(50) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE sources (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    title VARCHAR(255) NOT NULL,
    episode_url VARCHAR(500),
    ingested_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    content_hash VARCHAR(64) UNIQUE
);

CREATE TABLE chunks (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    source_id UUID NOT NULL REFERENCES sources(id) ON DELETE CASCADE,
    content TEXT NOT NULL,
    position INT NOT NULL,
    embedding VECTOR(384)
);

CREATE INDEX IF NOT EXISTS idx_chunks_embedding 
ON chunks USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);

CREATE TABLE artifacts (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    session_id UUID NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
    type VARCHAR(20) NOT NULL CHECK (type IN ('markdown', 'html')),
    content TEXT NOT NULL,
    sanitized BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

## 3. REST API Contract

### `GET /health`
- **Response `200 OK`**: `{"status": "ok", "database": "connected", "llm_provider": "ollama", "provider_available": true}`
- **Response `503 Service Unavailable`**: Standard error envelope if DB connection fails.

### `POST /sessions`
- **Request**: `{}` (optional `client_metadata`)
- **Response `201 Created`**: `{"session_id": "uuid-v4-string"}`

### `GET /sessions/{id}/messages`
- **Response `200 OK`**: List of message objects including roles, content, citations, and created timestamps.

### `POST /sessions/{id}/messages`
- **Request**: `{"content": "What is PLG according to Elena Verna?"}`
- **Response `200 OK`**:
  ```json
  {
    "id": "msg-uuid",
    "session_id": "sess-uuid",
    "role": "assistant",
    "content": "Product-Led Growth (PLG) is...",
    "citations": [
      {
        "source_id": "src-uuid",
        "title": "Elena Verna on Product-Led Growth",
        "position": 1,
        "score": 0.82,
        "snippet": "PLG is not a sales strategy..."
      }
    ],
    "artifact": null,
    "model_provider": "ollama"
  }
  ```

### `GET /artifacts/{id}`
- **Response `200 OK`**: `{"id": "art-uuid", "session_id": "sess-uuid", "type": "html", "content": "...", "sanitized": true}`

### `GET /config`
- **Response `200 OK`**: `{"active_provider": "ollama", "model_name": "llama3.1:8b", "embedding_model": "all-MiniLM-L6-v2", "last_indexed_at": "2026-09-04T10:50:00Z"}`

## 4. Error Envelope
All error responses enforce a uniform JSON structure:
```json
{
  "error": {
    "code": "RESOURCE_NOT_FOUND",
    "message": "Session with ID ... not found",
    "detail": {}
  }
}
```
- Validation errors return HTTP `400 Bad Request`.
- Upstream model/DB errors return HTTP `502 Bad Gateway` or `503 Service Unavailable` with body details. Bare 500 errors are trapped.

## 5. Security & Sanitization Model
- HTML artifacts generated by LLMs pass through `sanitizer.py`.
- Strips: `<script>`, `<style>`, `<iframe>`, `<object>`, `<embed>`, inline event handlers (`onload`, `onerror`, `onclick`), and unsafe URI schemes (`javascript:`, `data:`).
- Safe elements permitted: `<div>`, `<span>`, `<h1>`-`<h6>`, `<p>`, `<ul>`, `<ol>`, `<li>`, `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`, `<code>`, `<pre>`, `<strong>`, `<em>`, `<a>` (with `rel="noopener"`).
- Client renders HTML inside `<iframe sandbox="allow-forms" srcdoc="...">` strictly omitting `allow-scripts`.

## 📝 Implementation Notes & Design Decisions

1. **CPU-Forced Embeddings (`device="cpu"`)**: SentenceTransformers model loading explicitly targets CPU memory (`device="cpu"`) to guarantee 100% cross-platform hardware compatibility across heterogeneous GPU/CPU environments without PyTorch CUDA binary mismatch errors.
2. **Zero-Touch Startup Ingestion**: FastAPI backend startup lifespan (`backend/app/main.py`) automatically initializes `pgvector` extensions, creates SQL tables, and triggers transcript ingestion on fresh container launches if the `sources` table is empty.
